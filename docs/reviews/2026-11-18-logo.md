# Logo: a real mark instead of the plain wordmark (#250)

**Date:** 2026-11-18. **Panel:** all 8 personas (brand touches every screen, and the home-screen icon matters most to readers). One findings + vote round. Majority decides.

**Question:** which of 4 concepts should become the biblestdy logo (lockup in header / sign-in / landing / error, tab icon, home-screen icon), and what must change before it ships?

**Evidence:** `2026-11-18-logo/concepts-sheet.png` (true pixels). Each concept: lockup at 18 and 14px in Paper light/dark and Clean light/dark, a large mark, the tab icon at 16 / 32 / 16px×6 with mock browser tabs, home-screen tiles, and a 390px phone header. Sources: `2026-11-18-logo/concepts.mjs`. Wordmark everywhere: Geist Mono 600 (the site's own font). Mark: currentColor SVG.

## Concepts

| | Concept | Idea |
|---|---|---|
| A | Ribboned book | Today's gold open book, plus a ribbon marker. Continuity. |
| B | Pen ring | A hand-drawn loop circling a line: the margin-scribing gesture. |
| C | b with ribbon | A lowercase-b monogram whose bowl drops a ribbon marker. |
| D | Highlighted page | A page with three lines, the middle one under a marker wash. |

## Votes

| Persona | 1st | 2nd | Veto |
|---|---|---|---|
| Jonas | C | A | D: stock "file-text" glyph; the wash vanishes at 16px |
| Sofie | A | C | B: reads as "remove" / "blocked" (⊖) |
| Mads | C | A | B: ⊖, and the drawn loop fights the mono wordmark |
| Ruth | A | C | B: no-entry sign; puts the pen above the text |
| Birthe | A | C | B: "a coffee bean or a no-entry sign" |
| Elias | C | B | D: lost among PDF and Docs tabs |
| Kasper | C | A | B: ⊘ at 16px and in Clean |
| Freja | C | A | D: "a document scanner or Google Docs" |

**Result: C wins, 5–3** (Jonas, Mads, Elias, Kasper, Freja vs Sofie, Ruth, Birthe for A). All but Elias put the other front-runner second. B was vetoed by 5 and D by 3, and neither got a first vote.

**Why C:** it is the only mark that stays a distinct, ownable silhouette at a real 16px (Jonas, Elias, Kasper). It comes from the name, so it sits beside the mono wordmark as a type companion rather than a pasted-in icon (Mads). It is modern and not churchy (Freja, Kasper).

**Why the minority wanted A:** an open book says "Bible" without help (Sofie), and readers keep the icon they already have on their home screen (Birthe, Ruth). The ribbon carried meaning for them too ("your place is kept").

**What we kept from A:** the same dark tile #211d18 and gold #d9b36a, so the home-screen icon still looks like the same app (Birthe F2, Freja F5). We also kept A's ribbon, now as C's notched tail (Elias F5). Ruth's point about distance from other Bible apps' book tiles (F4) is met more fully by C, which is not a book at all.

## Refinements applied (from the winner's findings)

| # | Change | Raised by |
|---|---|---|
| R1 | **No "b biblestdy" stutter.** The gap is now 0.55em (was 0.38, about one mono space). The mark is 1.2em, so its stem stands a little above the wordmark's ascender and reads as a symbol. | Freja, Elias, Kasper, Mads |
| R2 | **Stroke matches the wordmark.** Measured Geist Mono 600 stem = 0.11em, so the stroke is 2.2/24 × 1.2em. Mads proposed 1.6, based on a 0.085em stem estimate; the measurement backs Kasper's ~0.12em instead. | Kasper, Mads |
| R3 | **Ribbon hangs plumb** from the centre of the bowl's base (x 11–14), down to y 23, with a notch 2 units deep. It now reads as a bookmark, not a hook or a "g". | Mads, Elias, Freja |
| R4 | **Flat stem top** (butt cap), like Geist's b/l/d. The bowl keeps round joins. | Mads |
| R5 | **Pixel-fitted 16px tab icon** (`favicon.svg`, 16-unit grid): 2px stem at x 4–6, 2px bowl, the ribbon as a plain 2px tab (the notch can't survive 16px). Crisp at 32px too. `favicon.ico` = that design at 16 and 32, plus the full mark at 48. | Jonas, Mads, Kasper, Elias, Freja |
| R6 | **Home-screen icons:** dark tile only. `apple-touch-icon` is full bleed (iOS masks the corners itself). `pwa-192/512` are rounded. `pwa-maskable-512` is full bleed with the mark at 62%, well inside the 80% safe circle. | Jonas, Sofie, Kasper, Elias, Freja |
| R7 | **Sized in em, with intrinsic size:** `width/height="1.2em"` on the `<svg>`, so there is no unsized flash, and it scales with 200% and large text. `aria-hidden` + `focusable="false"`. The bowl's base sits on the baseline (`vertical-align:-0.27em`). | Jonas, Sofie |
| R8 | **One component** (`components/logo.tsx`, used at all 8 call sites). The icons come from one script (`tools/brand/make-icons.mjs`), so nothing drifts. | Jonas |
| R9 | **The mark never stands alone in the nav.** It shows only where the wordmark already shows: the reader row at ≥56rem, unchanged. No hover effect or animation. | Sofie, Kasper (vs Elias F3) |

## Conflicts + decisions

- **Mark-only home link on narrow reader rows** (Elias F3) vs **never alone in the nav** (Sofie F2, Kasper F4, plus the standing "never an icon alone" rule from the 2026-11-15 navigation review). Decision: not added. Jonas F4 (an unnamed link) is moot as a result.
- **Lockups stacked on landing / sign-in, no mark beside the wordmark** (Mads F1, alone). Decision: inline lockup everywhere. The owner asked for a logo where the wordmark is, and no other persona objected to inline. Recorded for a later look.
- **Logo destination for signed-in readers** (Sofie F3): out of scope here, and unchanged (`/`). Listed under later.

## Not changed

- Link names: on sign-in, landing, error, privacy and copyright the link's name is the text "biblestdy". The reader nav keeps its existing `aria-label` "biblestdy home" / "biblestdy forside", which starts with the visible text (label-in-name holds).
- The manifest `theme_color` / `background_color` and `<meta theme-color>` stay as they are (#211d18 / #f6f2e9). They already match the tile.
- There is no og image to update.
