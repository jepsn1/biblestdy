## Conflicts → recommendations
- Zoom lock: panel says unblock; **Marcus: keep** → text-size setting.
- Words vs calm: tooltips desktop, labels tablet/desktop-wide, labelled "More" on phone.
- ⌘K palette vs jump box: extend jump box with result groups (Jonas: it's already a correct combobox).
- Running head: one footer line with verse range; drop top head.
- Sign-out confirm: yes (rare action, costly mistake for low-tech readers).
