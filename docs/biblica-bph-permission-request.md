**Product name:** biblestdy (biblestdy.com)

**Requesting:** Non-commercial digital display license for *Bibelen på
hverdagsdansk* (BPH), ideally delivered as Digital Bible Library access linked
to our API.Bible key (key id on request) — the same channel Biblica already
uses for its open translations.

**What the product is:**
biblestdy is a personal Bible-study web app built around the experience of
writing in a paper Bible: readers highlight spans of verse text, scribble
handwritten-style annotations in the margins, and attach longer study notes
that can be anchored to multiple passages. The text is displayed as a fixed,
book-like two-column spread — no scrolling feed, no fragmenting of the text.
What makes it unique: annotations are anchored to word-level positions inside
the verse text, so a reader's accumulated study — highlights, margin notes,
cross-references, topic tags — compounds over years, resurfacing automatically
whenever they return to a passage, in any translation they read.

**How BPH would be used:**
- Display-only rendering of chapter text inside the app's reader, alongside
  the English translations we already license via API.Bible (NIV 2011 et al.).
- Verse text is fetched on demand and cached at most 24 hours; we store no
  permanent copy of the translation, no offline/download capability, no audio,
  no derivatives. Users' annotations reference word positions, never
  reproduce the text.
- Copyright notice displayed on every chapter (already implemented — we show
  the copyright line API.Bible/DBL provides).

**Scale + commercial status:**
Currently a free, non-commercial pilot with a small circle of Danish users
(< 100). Danish readers are the core audience; BPH is the modern Danish
translation they know and ask for. If the product later charges, we will
return to Biblica for a commercial license before doing so.
